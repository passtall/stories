# Ranked mystery stories

Fifteen new, complete narratives, ordered by editorial judgment of their interest: the strength of the opening mystery, investigative turns, unusual evidence, human stakes, and the eventual payoff. The order is subjective, informed by the preferences in `../agents.md`; it is not a factual score of how important an event was.

Titles and reading notes avoid the central explanations. Sources and evidence qualifications appear at the end of each story. All 71 cases the user confirmed as already heard were excluded. The original `../stories.md` is that earlier list, not this batch’s contents.

## Research and reading

These are substantial prose narratives, generally around 1,500–1,800 words each, rather than case summaries. Their combined length is roughly 25,000 words. The numerical order is the interest ranking; readers seeking category variety can alternate among categories using the table.

Research used accessible FBI histories, John Snow’s original 1855 publication, BBC reporting, CDC guidance, and Wikipedia articles with referenced case chronologies. Several narratives rely on secondary accounts; each file identifies exactly which sources were consulted and distinguishes participant claims, official conclusions, and unresolved details. Links to unavailable sources are not treated as sources that were read. This is a researched first batch, not an assertion that every underlying court record or scientific paper was independently reviewed.

All fifteen completed case identifiers have been added to `../already-told-stories.md` to prevent repeats in future batches. That file includes spoilers and is intended as a continuity record, not a reading index.
